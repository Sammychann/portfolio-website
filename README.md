## ✨ Features

- **4,000+ GPU Particle System**: Custom GLSL vertex & fragment shaders with interactive mouse repulsion physics.
- **Dark / Light Mode**: 🌙 Moon & ☀️ Sun single toggle button in top-right with porcelain luxury light theme and 3D particle color lerping.
- **Swift Navigation Side Graph Bar**: Interactive vertical node indicator tracking scroll progress with smooth click jumping.
- **Minimalist Vertical Work Graph**: Interactive timeline tree showcasing experience at **SailPoint** (with live link) and **Elliot Systems**.
- **Word-by-Word Scroll Reveals**: GSAP ScrollTrigger text highlights and animated numeric counters.
